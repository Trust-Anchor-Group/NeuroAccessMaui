# Computer vision test images

The images in this directory are fixtures for the computer vision unit tests in `IdApp.Cv.Test`.

## Source references

Photos from these sources have been used in the tests:

- [PassportEye project on GitHub](https://github.com/konstantint/PassportEye)
- [Detecting machine-readable zones in passport images](https://www.pyimagesearch.com/2015/11/30/detecting-machine-readable-zones-in-passport-images/)

Keep source attribution when adding or replacing fixtures. These image fixtures are separate from [DevTestPlatform's visual scenario fixtures](../../DevTestPlatform/README.md).
